# Support

This repository is a sample implementation for learning and demonstration. It is not an official Microsoft product, service, or support offering unless published through an approved Microsoft channel.

For Microsoft Fabric product support, use the official Microsoft support channels and Fabric documentation.

For issues with this sample, open a GitHub issue with:

- The script or documentation page involved.
- The Fabric surface you used.
- The exact error message, with private tenant details removed.
- The minimal sample input needed to reproduce the issue.
